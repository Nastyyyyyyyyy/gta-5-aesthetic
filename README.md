# gta-5-aesthetic

Images des interfaces du serveur Velocity (vêtements, tatouages, visage, PNJ, véhicules, armes, objets, emotes),
en WebP léger, rangées comme les lit le jeu : `<base>/clothes/<male|female>/<composant>/<drawable>_<texture>.png.webp`.
Servies par GitHub Pages ; base à mettre dans `velocity_images_base`.
